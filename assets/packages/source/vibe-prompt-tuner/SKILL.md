# Vibe Prompt Tuner

1. Identify missing goal, context, constraints, inputs, outputs, and acceptance criteria.
2. Rewrite the prompt so the agent can act without unnecessary clarification.
3. Preserve the user's intent and tone while making the task testable.
4. Include a compact checklist for verifying the agent's output.

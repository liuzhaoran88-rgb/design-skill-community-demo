# Feedback Insight Synthesizer

1. Group feedback by recurring user need or observed behavior.
2. Keep direct evidence attached to each theme.
3. Separate evidence, interpretation, and recommended opportunity.
4. Prioritize opportunities by frequency, impact, and confidence.

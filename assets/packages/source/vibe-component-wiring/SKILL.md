# Vibe Component Wiring

1. Inventory components, inputs, outputs, and user-triggered events.
2. Define loading, empty, error, success, and retry states before coding.
3. Connect state transitions with the smallest clear local model.
4. Keep event names, props, and data shapes easy to inspect and modify.

# Copy Length Precheck

1. Identify constrained text containers and key UI states.
2. Check likely truncation, wrapping, and overflow risks.
3. Include mobile and localization considerations when the target platform is known.
4. Return a concise list of risks with recommended copy or layout adjustments.

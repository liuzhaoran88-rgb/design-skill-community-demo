# Vibe PR Summary

1. Read the diff or commit summary and identify user-facing changes.
2. Group related code changes by behavior, UI, data, and infrastructure.
3. Call out risks, migrations, and test coverage honestly.
4. Return a PR-ready summary with verification steps.

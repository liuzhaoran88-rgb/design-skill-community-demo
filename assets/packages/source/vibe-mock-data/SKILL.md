# Vibe Mock Data

1. Infer entities, field types, and relationships from the supplied UI or schema.
2. Generate normal, boundary, empty, and error-like examples.
3. Keep values believable for product demos without including sensitive personal data.
4. Return data in the format the project can use directly.

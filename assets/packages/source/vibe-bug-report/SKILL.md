# Vibe Bug Report

1. Separate observed behavior, expected behavior, environment, and reproduction steps.
2. Extract likely clues from logs, screenshots, and recent changes.
3. Ask only for missing information that blocks reproduction.
4. Produce a concise report with suspected causes and verification steps.

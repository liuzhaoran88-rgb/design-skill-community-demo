# Component Naming Assistant

1. Inspect existing component, layer, and variable names.
2. Infer the local naming pattern before suggesting changes.
3. List inconsistent names and propose a normalized replacement.
4. Preserve meaningful product vocabulary and flag ambiguous names for review.

# Handoff Document Generator

1. Read the supplied design link and identify the requested page or node.
2. Convert white-background copy into Markdown text.
3. Preserve grey-background examples as screenshots between the relevant sections.
4. Summarize visual states, interactions, and edge cases for engineering review.

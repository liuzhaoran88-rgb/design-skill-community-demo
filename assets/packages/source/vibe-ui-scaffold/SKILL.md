# Vibe UI Scaffold

1. Clarify the target user, primary task, and expected first screen.
2. Choose the smallest runnable implementation that matches the existing project style.
3. Build semantic structure, responsive layout, core states, and useful placeholder data.
4. Finish with concise run instructions and visible next iteration points.

# Design Spec Check

1. Read the supplied design link and identify the target page or node.
2. Review spacing, color, typography, and component consistency.
3. Return issues grouped by severity, with the observed state, relevant rule, and an actionable fix.
4. Mark uncertain cases for designer confirmation rather than inventing a rule.
